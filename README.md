# Cybersecurity Notebook

Личен статичен сайт за подреждане на бележки по киберсигурност.

## Отваряне

Отвори `index.html` в браузър. Сайтът не изисква build процес или външни зависимости.

## Файлове

- `index.html` — интерфейсът и основната функционалност на сайта.
- `metasploit-notes.js` — структурирани бележки за Metasploit.
- `images/` — изображения, използвани в бележките.

Записите, добавени през интерфейса, се съхраняват в `localStorage` на текущия браузър. Те не се синхронизират автоматично през GitHub.
